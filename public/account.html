この端末の ID

この端末には、メールアドレスなどを使わない匿名の ID があります。kan-game.app のゲームはこの ID で記録を保存します。

退会の途中で止まっています。下の「退会する」をもう一度押してください。押さなくても、時間をおいて自動でやり直します。

別の端末へ引き継ぐ

引き継ぎコードを発行し、10 分以内に別の端末のこの画面か、ゲームの設定画面で入力してください。コードは 1 回だけ使えます。

残り

復旧コード

この端末のデータを消したときに ID へ戻るための、ただ 1 つの手段です。発行したら、紙に書くか、パスワード管理アプリに保存してください。コードはこの画面で一度だけ表示されます。

発行し直すと、前のコードは使えなくなります。

この画面を離れると、もう表示できません。

コードを入力して ID を切り替える

別の端末で発行した引き継ぎコード、または控えておいた復旧コードを入力すると、この端末の ID がそのコードの ID に切り替わります。今の ID の記録は、切り替え先へまとめられません。

退会

ID と名前、すべてのゲームの記録を削除します。ゲームごとの削除はできません。削除した記録は元に戻せません。

退会しました。この端末で次に kan-game.app を開くと、新しい ID が作られます。
