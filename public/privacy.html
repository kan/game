プライバシーポリシー

伏原 幹（以下「運営者」）は、kan-game.app とそのゲーム（以下「本サービス」）で扱う利用者の情報を、このポリシーに沿って取り扱います。

1. 本サービスの ID

本サービスは、メールアドレスや氏名を使わない匿名の ID で利用者を見分けます。ID は、端末で本サービスを初めて開いたときに自動で作られ、ブラウザの Cookie に保存されます。

  • Cookie の名前は __Secure-kg_id で、kan-game.app とそのサブドメインのページに送られます。中身は ID と、運営者が付けた署名です。
  • 有効期限は 400 日で、本サービスを開くたびに延長されます。ページのスクリプトからは読めない設定（HttpOnly）にしています。
  • 本サービスがブラウザに置く Cookie はこれだけです。広告やアクセス解析のための Cookie は置きません。

ブラウザのデータを消すと ID は失われます。ID に戻る手段は、アカウント画面で発行した復旧コードだけです。運営者は ID を復元できません。

2. 取得する情報

kan-game.app 全体

  • ID、ID を作った日時、最後に本サービスを開いた日（1 日単位）
  • 名前（設定した場合）
  • 引き継ぎコード（発行から 10 分で無効になります）
  • 復旧コードと引き継ぎ用トークン。どちらも元に戻せない形（ハッシュ）に変えて保存し、コードそのものは保存しません

ゲームごとの記録

各ゲームは、ID に結び付けてプレイの記録を保存します。TAKO-SEN では次のとおりです。

  • クリアした問題、開始と完了の日時、かかった時間、ミスの回数、ヒントの回数と段階
  • デイリーと超級の挑戦の記録
  • ランキングへの公開に同意したことと、その日時
  • デイリーの通知をオンにした端末の、通知の送り先と暗号化の鍵。送り先は、ブラウザの通知サービス（Google、Mozilla、Apple、Microsoft のいずれか）が発行する URL です。その端末の ID に結び付けて保存し、1 つの ID につき 20 台までです

クリアの記録は、名前を設定する前から本人の履歴として保存します。公開するのは、名前と公開への同意を設定した後のクリアだけです（4 を参照）。

通信の情報

  • IP アドレスは、同じ接続元からの大量の操作を防ぐため、ID の作成とコードの入力の回数を数えるときに使います。運営者のデータベースには保存しません。
  • 本サービスを動かしている Cloudflare のログ機能に、リクエストとレスポンスの内容、それに関連する情報（日時、URL、IP アドレスなど）が記録され、7 日間で消えます。運営者は障害の調査にだけ使います。

端末の中だけに保存する情報

各ゲームは、設定、プレイ中の盤面、端末での成績などをブラウザ（localStorage）に保存します。これらは、2 に挙げたものを除き、運営者へ送りません。

取得しない情報

メールアドレス、氏名、電話番号、位置情報は取得しません。アクセス解析や広告の仕組みも使っていません。

3. 利用目的

  • ゲームの記録を保存し、別の端末へ引き継げるようにするため
  • ランキングを作って表示するため
  • 通知をオンにした端末へ、デイリーの開始（毎日 0:05、日本時間）を知らせるため
  • 不正な操作や大量のアクセスを防ぐため
  • 障害の調査と、本サービスの改善のため
  • 問い合わせに答えるため

4. 公開される情報

名前を設定し、ゲームごとのランキングへの公開に同意すると、そのゲームのランキングに次の情報が載り、誰でも見られます。

  • 名前
  • 成績。TAKO-SEN では、問題ごとの最初のクリアの時間、ミスの回数、ヒントの回数と段階、週ごとのクリア数と平均時間です

ID、日時、名前の設定前の記録は公開しません。名前の設定前に解いた問題は、設定後に解き直しても公開しません。

5. 第三者への提供と委託

法令に基づく場合を除き、利用者の情報を第三者に提供しません。

本サービスは、米国の Cloudflare, Inc. のサービス（Workers と D1）で動かしており、2 の情報は同社の設備に保存されます。同社の情報の取り扱いは、同社のプライバシーポリシーに従います。

デイリーの通知は、利用者のブラウザが使う通知サービス（Google、Mozilla、Apple、Microsoft のいずれか）を経由して届きます。運営者がその通知サービスへ送るのは、送り先と、暗号化した通知の本文だけです。本文は全員に同じ固定の文で、ID や名前は含みません。通知サービスの情報の取り扱いは、各社のプライバシーポリシーに従います。

6. 保存する期間

  • ID、名前、ゲームの記録は、退会するまで保存します
  • 通知の送り先は、その端末で通知をオフにするか、退会するまで保存します。通知サービスが無効と答えた送り先は、そのときに消します
  • 引き継ぎコードは 10 分、Cloudflare のログは 7 日で消えます
  • データベースのバックアップには、消した情報が最長 30 日残ります

7. 退会と、退会で消えるもの

アカウント画面から退会できます。退会すると、ID、名前、引き継ぎコード、復旧コード、引き継ぎ用トークンと、すべてのゲームの記録、ランキングの掲載、通知の送り先を消します。ゲームごとの退会はできません。

次のものは、退会しても残ります。

  • 各ゲームが、退会した ID からの書き込みを断るために保存する、その ID の値
  • 共有した盤面など、誰の ID とも結び付けずに保存しているもの
  • 端末のブラウザに保存されたデータ（ブラウザで消してください）
  • ほかの人が保存したランキングの画面などの写し

TAKO-SEN の開発版から移した記録

TAKO-SEN の開発版（tako-sen.kan-fushihara.workers.dev）の記録と名前は、本サービスの公開にあわせて新しい ID へ移しました。開発版で引き継ぎの手続きをすると、その記録を自分の ID として使えます。手続きの期間（公開から 3 か月）が過ぎても引き継がれなかった記録と名前は、ほかの利用者の順位を変えないため、ランキングにそのまま残します。削除を希望する場合は、11 の連絡先へご連絡ください。

8. 開示などの請求

保存している情報の開示、訂正、削除を求める場合は、11 の連絡先へご連絡ください。ID は匿名なので、本人であることを確かめるために、その端末で発行した引き継ぎコードなどをお願いすることがあります。

9. 安全のための取り組み

  • 通信はすべて HTTPS で暗号化しています
  • ID の Cookie には署名を付け、書き換えられたものは受け付けません
  • 復旧コードと引き継ぎ用トークンは、元に戻せない形で保存しています

10. 未成年の方へ

未成年の方は、保護者の方と内容を確かめてから本サービスを利用してください。名前には本名や連絡先を使わないでください。
